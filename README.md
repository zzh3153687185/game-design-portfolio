## 项目速览

### A.《灵域天空岛》（2D 沙盒自动化）

| 项 | 内容 |
|---|---|
| 角色 | 同人独立游戏团队 · **策划负责人** |
| 时间 | 2025.09 – 至今 |
| 职责 | 主导系统设计与玩法框架；产出可评审策划文档与数值向配置思路；推动程序/美术协作落地 |
| 设计重点 | 核心循环收敛；**生产 / 物流 / 存储**职责边界；以产能匹配与反压反馈替代「带速微操」假深度 |

### B. 崩坏：星穹铁道 · 肉鸽玩法（个人分析与改版）

| 项 | 内容 |
|---|---|
| 类型 | 竞品拆解 + 改版策划 |
| 职责 | 拆解体验目标与结构链路；输出改版方案，并完成相关模块配置实践 |
| 设计重点 | 局内成长、随机性、多周目动力；规则是否服务体验目标 |
