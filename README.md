## 项目速览

### A.《灵域天空岛》（2D 沙盒自动化）

| 项 | 内容 |
|---|---|
| 角色 | 同人独立游戏团队 · **策划负责人** |
| 时间 | 2025.09 – 至今 |
| 职责 | 主导系统设计与玩法框架；产出可评审策划文档与数值向配置思路；推动程序/美术协作落地 |
| 设计重点 | 核心循环收敛；**生产 / 物流 / 存储**职责边界；以产能匹配与反压反馈替代「带速微操」假深度 |

### B. 崩坏：星穹铁道 · 肉鸽玩法（拆解到改版）

| 项 | 内容 |
|---|---|
| 类型 | 竞品拆解 + 不足诊断 + 改版策划（单文档完整链路） |
| 职责 | 对比星铁/方舟肉鸽结构；定位耐玩短板；基于差分宇宙输出可配置改版规则，并完成黑潮/纪元/往世余影等配表实践 |
| 设计重点 | 体验目标对齐；道中策略回流；倒计时与随机变量；未验证点与迭代指标设想 |
