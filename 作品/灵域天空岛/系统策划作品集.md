## 2. 定位与核心循环

### 2.1 定位

| 项 | 内容 |
|---|---|
| 类型 | 沙盒 · 工业自动化（2D） |
| 体验关键词 | 孤岛探索 · 资源驱动科技 · 产线自动化 · 灵力布局决策 · 阶段式世界推进 |
| 世界框架 | 四大界域；每界主岛 + 小岛；岛间虚空不可步行通行 |

### 2.2 核心玩法循环

1. **探索** — 发现岛屿、资源点与通行条件  
2. **收集** — 获取原料与关键进程资源  
3. **建造** — 落位产线单元、连通物流与灵力  
4. **发展** — 解锁科技、升级工具与通行能力  
5. **调控** — 监控瓶颈、优化布局与配方，再驱动下一轮探索  

口径：玩家行为本身不耗灵力；灵力由器械与产线运转消耗；建造环中的模块化产线，由生产与物流规则承接。

### 2.3 产业链骨架

```text
采集 / 采集类设备
  → 磨制、熔炼、反应、压制等中间加工（常持续生产）
  → 零件等中间件
  → 总装类设施（常指定数量）
  → 装备、可放置设备
```

## 3. 整体系统架构

产线体验拆为三个并列系统：**生产、物流、存储**。划分依据是物品在该节点上发生什么，而不是界面外观。

### 3.1 划分原则

| 原则 | 含义 |
|---|---|
| 按物品语义切分 | 转换 / 搬运 / 保管 各成一系统 |
| 端口统一、职责分治 | 输入口 / 输出口形态一致，接受规则由所属系统叠加 |
| 配置拉开差异 | 同类设施共用规则与 UI，等级与配方走配置表 |
| 边界先于细则 | 先冻结「谁负责什么」，再写内部规则 |

### 3.2 三系统边界（摘要）

| | 生产 | 物流 | 存储 |
|---|---|---|---|
| 核心职责 | 转换物品（执行配方） | 搬运物品（种类不变） | 保管 / 转发（不转换） |
| 玩家决策点 | 设施、配方、持续 / 指定 | 布局连通、产能匹配、读反压 | 库存整理、筛选、仓库节点 |

一句话定界：**生产负责变，物流负责搬，存储负责放。**

生产内部按大类组织（近身合成、采集、磨制 / 熔炼 / 反应 / 压制、总装、分支工艺等）；同类多等级共用 UI，差异进配置。通用骨架（配方锁端口、单次用量、持续 / 指定、统一停工、改配方退料）见专项案例。

## 4. 模块关系摘要

```text
存储（箱子 / 背包）
    │ 手塞 / 取出
    ▼
生产输入口 ──配方转换──▶ 生产输出口
    ▲                         │
    │         物流通路（一带一种 + 单格缓冲）
    └──────── 反压 / 供料 ◀────┘
                    │
                    ▼
              下游生产 / 存储端口
```

| 关系 | 摘要 |
|---|---|
| 生产 ↔ 物流 | 端口即端点；缓冲顶满触发上游停工；改配方退料回通路 |
| 物流 ↔ 存储 | 缓冲模型对齐单格堆叠；Bmax = 堆叠上限 |
| 生产 ↔ 存储 | 手塞等同物流写入；生产口只服务下一次制作 |
| 表现 | 红 = 堵塞 / 停工，三系统共用 |

向上接口：灵力影响大型产线效率；科技树解锁设施与配方；五行客制化在配方上叠加辅料决策；仙台作为特殊物流节点。

反压、退料禁止条件、筛选拒收、端到端配表与校验 → **《生产·物流·存储系统设计案例》**。

## 5. 创新点摘要

| 传统参照 | 本项目做法 |
|---|---|
| 传送带速率养成 | 通路无独立额定产能；策略在产能匹配与反压阅读 |
| 工厂流水 vs 背包合成两套逻辑 | 持续 / 指定双模式，一套生产骨架 |
| 连续地块平面工厂 | 天空岛 + 飞行器 / 仙台 / 跨界传送 |
| 纯布局自动化 | 叠加区域灵力与五行配方决策 |
