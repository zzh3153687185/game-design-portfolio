## 1. 项目目标与约束

部门要做员工个人年度总结 H5：用交付、协作数据让人感到这一年被看见。上级希望并行看到多套完整想法再选型，而不是只改语气的一版。

- 载体：手机竖屏 H5，约 14 个信息主题。
- 语气：鼓励、认可；禁止考核压迫与无必要横向攀比。
- 数据：业务底稿 + 部分飞书字段；口径冻结在《数据说明》。公开仓库不写真实姓名、业绩、地域等明细。
- 交付阶段：已完成策划、线框与可点 Demo、多轮评审与交接整理；**未进入正式开发上线**；公开材料无真实用户数据。

### 显隐实例（简历正式案例）

> 满足条件时使用独立页面；不满足则按关联程度合并或不展示。

**实例 A · 超越比例**  
条件：`≥50%`。满足：交付投入页追加相对位置句（全报告唯一同事比较）。不满足：整句不渲染，其余两项仍在。避免低比例写成压力。

**实例 B · 担任经理**  
条件：任一经理次数 &gt;0。满足：独立页列次数。不满足：保留该信息主题，走条件文案，不展示次数列表、不施压。

**实例 C · 非普适高光**  
条件：五项中至少一项有数据。满足：只渲染有数据项。不满足：整页不进入浏览流。

## 4. 展开：第二版 · 轻交互叙事（小羊观影）

### 4.1 一句话与情绪曲线

员工打开 H5 后，由「事业运小羊」邀请进入电影院，在银幕上观看自己的 2026 交付故事；末页生成可分享的小羊明信片。

```text
Loading / Home / 入场
  → 拉近入戏（封面开场）
  → 中段数据铺陈（各信息主题）
  → 高光庆祝（条件页）
  → 致谢收束
  → 明信片留念
```

### 4.2 与共用口径的关系

- **口径统一**：14 个信息主题、数据字段、分支与显隐逻辑沿用冻结规则；超越比例仍仅交付投入页且 ≥50%。  
- **表现替换**：载体从「白底翻页长文」换成「竖屏影院观影」；旁白 + 角色对话演出。  
- **文案**：以分页台本为唯一台词来源。

### 4.3 已锁定的表现决策

| 项 | 结论 |
|---|---|
| 美术风格 | 暖暗影院 |
| 角色画风 | SD / 卡通大头贴纸（白描边）；否决写实半身 |
| 银幕主路 | 微缩场景投影为主 + 点击驱动场景微反馈 |
| 页面结构 | 主题底图 → 底图上叠数据图形 → 空白处出员工+小羊贴纸对话 → 屏幕下方旁白条（数字高亮） |
| 旁白形态 | 银幕内底部字幕条，一字字打出；角色气泡整句出现 |
| 避让规则 | 旁白与气泡不得长时间遮挡银幕主内容 |
| 构图模式 | 宽景（入场/收束）· 银幕全屏报告页（数据主路）· 物件页（封面/明信片） |
| 缺数据极端空值 | 业务保证不会出现；不另写降级分支 |
| 音效 | 不进本策划案 |

### 4.4 交互与完成度

- 主交互是**点击继续 / 点击揭示**，每页至少一种服务于信息揭示的微反馈，不做成操作型小游戏。  
- 用户负担中等：比纯翻页多一层演出，但远低于闯关方案。  
- **可点 HTML Demo 已完成**（策划案 / 台本定稿后，按锁定风格重建演示）。  
- 正式开发上线：否。

## 5. 一次真实评审迭代（第二版）

### 案例 · 银幕结构对齐与字幕避让

| 步骤 | 内容 |
|---|---|
| 原方案 | 早期线曾试「三区座位常驻、全程不拉近」等构图；大头曾偏写实半身 |
| 收到的意见 / 自检 | 观影感不够；旁白与气泡容易挡住数据主内容 |
| 判断 | 第二版差异应落在「读法与仪式」，不能牺牲数字可读；构图必须按页约束 |
| 修改选择 | 废弃错误线；锁定暖暗影院 + SD 贴纸大头；改为「底图→数据图形→贴纸对话→底栏旁白」 |
| 修改后的规则 | 写入第二版版本记录；Demo 按新结构重建 |
| 尚未验证 | 真数据下演出是否仍抢戏；多机型字幕可读性 |

## 6. AI 使用边界（一例）

AI 用于扩写与对齐已有格式；框架、禁区、口径、取舍由我拍板。

例：模型曾批量生成偏套话的收束句、并滥用「这一年」开头 → 我写入禁区词簇与句式规范，限制全报告「这一年」不超过 3 次，要求主题钩子多样化 → 最终以设计思路总结禁区 + 台本/Axure 定稿为准。
