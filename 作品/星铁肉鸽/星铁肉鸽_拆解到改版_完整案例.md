## 1. 设计目的

### 1.1 为什么做这件事

抽卡养成向产品在主线与活动空窗期，常驻肉鸽往往承担「拉长在线、消耗热情、给角色发挥空间」的职能。星铁与方舟的肉鸽定位相近，但**耐玩结构不同**：方舟更偏「道中运营 + 多维决策」；星铁后期更偏「选流派 → 强化自身」，通关友好、适合周常，但**单局内体验同质、重复战斗多、策略维度偏窄**，爱好向玩家容易早倦。

### 1.2 改版要达成什么（体验目标）

| 编号 | 目的 | 设计落点（预告） |
|---|---|---|
| P1 | 降低「大量重复战斗」带来的枯燥 | 路线随机连通、纪元场地变化、敌人组合差异、负面奇物逼迫变阵 |
| P2 | 控制单局成本，便于多次尝试 | **黑潮**倒计时，目标单局约 1 小时；阶段存档；战斗失败可重试编队 |
| P3 | 增加道中策略维度 | 路线规划 + **往世余影**改线/改纪元；商店「搬空」博弈；首领火种削弱终局 |
| P4 | 保留惊喜与新鲜感 | 随机资源、事件、特殊敌人；祝福/方程/奇物组合打出异于普通模式的战斗 |
| P5 | 不推翻星铁既有肉鸽资产 | 未改动部分默认继承差分宇宙规则，改动可配置、可验收 |

## 2. 拆解思考（精炼）

拆解时不直接判「谁更好」，而按**模式职能 → 难度结构 → 开局策略 → 关卡供给 → 局内决策**对照二者迭代后的强版本，问同一问题：规则是否服务「重复游玩仍有新决策」。

### 2.1 肉鸽在产品中的职能

- 双方本体都缺少能长期「自己找事做」的开放内容，肉鸽是空窗期的重要去处。  
- 方舟倾向把叙事/特供模式与主游玩模式拆开，主模式更干净；星铁常把叙事与主模式绑在一起，前期文本负担更大。  
- **启发：** 改版优先服务「主游玩循环的策略密度」，叙事特供可后置，避免干扰核心决策节奏。

### 2.2 难度与人群覆盖

- 方舟高难层数多、debuff 与规则变化明显，爱好者能找舒适区并长期研究；顶难研究成本高。  
- 星铁低难友好、强度补偿对练度不足更友好；后期差分用段位驱动回访，但顶难操作门槛相对更低，重复解锁过程易耗热情。  
- **启发：** 改版不堆无效难度级数，而用**倒计时压力 + 路线/纪元变量**制造「同构筑不同局」的差异。

### 2.3 开局策略与局内决策重心

- 方舟分队强引导开局构筑，局内要同时处理发育、生存、目标与路线。  
- 星铁早期仍有一定路线运营；不可知域/差分后，决策重心转向「选玩法 → 堆资源实现想法」，自由度高、周常友好，但**道中运营变薄**，玩法多样性 × 局内同质性 = 热情消耗快。  
- **启发：** 在差分「选菜自由度」之上，加回**有代价的路线运营**（黑潮步数、余影资源），让「想玩什么」与「这局怎么走」重新耦合。

### 2.4 关卡与节奏

- 方舟节点类型多、Boss 多为主题向新战，重复感更低；商店/存款等支持长线规划。  
- 星铁大量复用本体场景与敌人，首领随机感强但主题差异弱；战斗节奏偏匀速重复。  
- **启发：** 用**纪元**做层间环境变量，用**交锋/火种**做阶段目标，用黑潮强制「不能无限刷同质战斗」。

### 2.5 拆解结论（一句话）

星铁肉鸽作为**周常消耗品**是成功的；若目标是**可长期重复的重要模式**，短板在于：**局内决策维度不足、重复战斗占比过高、单局时长与策略密度不匹配。** 改版以此为病开方。

## 3. 不足点 → 重设计映射

| 不足（来自拆解） | 重设计手段 | 对应目的 |
|---|---|---|
| 道中决策薄，选关近似「点下一间」 | 多层平行线 + 斜向/纵向连通；余影可改类型/改线 | P3 |
| 重复战斗多、单局易拖长 | 黑潮蔓延倒计时；超时狂暴/强制结算并加速黑潮 | P1, P2 |
| 同构筑局间差异不足 | 纪元轮换改变敌人权重与场地感；负面奇物逼变阵 | P1, P4 |
| 终局目标感弱 | 火种链（纷争/死亡/天空等）：中期选择影响黑潮决战 | P3, P5 |
| 商店策略单一 | 四类商店 +「搬空」高难战换全免；搬空后该 NPC 后续消失 | P3 |
| 失败惩罚过硬影响尝试欲 | 战斗可重试/重编队；阶段存档 | P2 |

**刻意不做：** 把方舟整套塔防运营搬进星铁；不重做全部敌人与场景美术；不扩大为「第八套完全独立肉鸽」，以差分宇宙为差分补丁，保证可落地。

## 4. 完整策划案（规则精炼）

> 基于《差分宇宙：千面英雄》。**未提及内容默认与差分宇宙一致。**

### 4.1 玩法概述

三层推进的路线肉鸽：玩家在随机连通图上移动；**纪元**按步轮换改变环境；**往世余影**作为消耗资源改写局面；**黑潮**自起点向右蔓延，形成全局倒计时；通关三层后与黑潮决战（或被提前追上则提前决战）。

设计关键词：**随机性 · 策略性 · 时限性 · 节奏性**。

### 4.2 核心机制

#### （1）往世余影（局内消耗资源）

- **获取：** 清小怪概率掉落；奖励/事件/奇物；击败首领固定获得等。  
- **使用时机：** 关卡选择界面，可一次消耗多种。  
- **效果类型（示例口径）：**  
  - 短窗战斗 Buff/敌方 Debuff（如「狂战」）  
  - 标记场上特定关卡（如奖励翻倍）  
  - 改变相邻节点类型（如变为遭遇）  
  - 切换/回溯纪元（如「纷争」临时 3 步）  

#### （2）黑潮（倒计时与终局）

- 开局行进约 7 步后，黑潮从起点向右按列蔓延；玩家每行动一步，黑潮推进一列（跨层计数）。  
- **先通关三层终关且未被追上：** 原地等待黑潮，按等待步数获得决战增益。  
- **被追上：** 立即进入黑潮决战，后续图节点不可再走。  
- **可影响蔓延：** 交锋胜延缓；事件/奇物延缓或加速；全灭加速等。  
- 决战为突发性战斗，不占用可选节点；指向性余影不可直接点选该战。

#### （3）纪元（层间场地变量）

- 主时间线按序轮换，默认每纪元持续约 5 步；额外纪元耗尽后回到主线剩余步数。  
- 特定纪元提高特定敌人出现权重，并赋予对应特殊效果（含「黑潮造物」等）。  
- 与余影、火种链联动（如纷争纪遭遇可触发尼卡多利选项）。

#### （4）火种链（中期选择 → 终局差异）

用「中期首领/事件选择 → 持有火种 → 黑潮决战是否被盗取技能」把单局故事线串起来。示例：

| 链 | 关键获取 | 持有收益 | 决战未持有风险 |
|---|---|---|---|
| 纷争 | 纷争纪遭遇 → 纷争之魂 → 击败纷争泰坦得火种 | 伤害↑ / 承伤↓ | 盗火行者获得纷争泰坦部分技能 |
| 死亡 | 三枚金血祝颂后特殊事件 → 冥河死龙 | 受伤回血 / 抵死一次 | 盗取死龙相关能力 |
| 天空 | （原案对应天象/天空火种链） | 命中/效果抵抗等 | 对应能力被盗 |

（完整奇物表以配表为准；公开版保留链路逻辑。）

### 4.3 界面与流程（要点）

1. **难度选择：** 进入方式对齐差分宇宙常规演算。  
2. **关卡选择：** 每层多条平行线 + 斜向/纵向通路；显示纪元剩余步数、黑潮覆盖态、余影入口。  
3. **层结构：** 三层；每层首列偏战斗/事件，末关固定首领；中间按原权重随机。  
4. **特殊层「冥河」：** 由死亡链触发；行动仍计黑潮；距黑潮 &lt; 5 步不可进入。  
5. **关卡结束：** 交互「盆中潮汐」返回选关。

连通规则摘要：左右必连通；连线不相交；每列纵向通路数量按概率生成（1/2/3 条）。

### 4.4 关卡设计要点

| 关卡 | 要点 |
|---|---|
| 通用战斗 | 超出限定回合敌方叠狂暴；再超时强制结束并加速黑潮（首领例外口径见下） |
| 商店 | 祝福/奇物/方程/余影四店；可「搬空」开战，胜则全免且该 NPC 后续商店消失 |
| 首领 | 可选首领；超时狂暴可叠但不强制清场；结束后进下层 |
| 交锋 | 新增；胜利延缓黑潮 |
| 其他 | 事件/奖励/休整等默认继承差分，奖励侧增加余影供给 |

### 4.5 配置落地（已实践）

改版中 **黑潮 / 纪元 / 往世余影** 等模块完成过配置表设计与字段维护（含批量校验思路），保证规则能落到可对接程序的表结构，而非停留在概念层。

## 5. 未验证点与迭代设想

### 5.1 尚未验证（诚实边界）

1. **黑潮步数曲线：** 7 步启动、单局约 1 小时是否在真实战斗时长下成立，需试玩台账。  
2. **余影经济：** 掉落率与强效余影是否导致「每局必改线」或「余影无感」。  
3. **纪元可读性：** 步数轮换是否造成信息过载；UI 是否够扫读。  
4. **搬空商店：** 风险/收益是否只有最优解；是否挤压正常购物。  
5. **火种压力：** 多链并行是否教学过重；盗取技能是否造成不公平突变。  
6. **相对差分宇宙的增量成本：** 程序/关卡/UI 工作量与体验提升比未做正式评估。

### 5.2 设想的验证与调参方向（仍属本玩法设计）

若进入试玩/上线，会优先用下列信号回看规则是否打中目的（P1–P3），再决定调黑潮节奏、余影投放或火种压力——**此处只列设计侧假设，不展开其他项目的运营经历**。

| 观察问题 | 可能信号 | 可能动作 |
|---|---|---|
| 是否仍在刷同质战斗 | 单局战斗次数、中途退出点 | 调黑潮 / 提高非战斗节点价值 |
| 策略是否变多样 | 余影使用分布、搬空选择率 | 削必选余影；补偿弱势路线 |
| 难度是否过头 | 黑潮决战胜率、火种持有率 | 调延缓手段与盗取强度 |
